# Что изменено в noScribe 0.8

Изменения внёс Ильдар Исламов, 13.10.2026. Места в коде помечены комментарием `Ildar:`.

Исходный проект: https://github.com/kaixxx/noScribe, тег v0.8 (коммит 03d4d18,
06.10.2026), автор Kai Dröge, GPL-3.0. Папка `engine` — его код с изменениями ниже.
Редактор `editor` — https://github.com/kaixxx/noScribeEditor без изменений.

1. **Без сети.** Удалена проверка новой версии на GitHub при запуске. Переменные окружения запрещают загрузку моделей из интернета (`HF_HUB_OFFLINE`, `TRANSFORMERS_OFFLINE`) и отправку статистики (`HF_HUB_DISABLE_TELEMETRY`, `PYANNOTE_METRICS_ENABLED=0`).
2. **Нарезка речи.** Поиск пауз — с настройками faster-whisper (2 с тишины, 0,4 с запаса) вместо 0,5 с и 50 мс. На записях разговоров с короткой нарезкой терялись куски речи и появлялись повторы. Значения меняются в настройках (`vad_min_silence_ms`, `vad_speech_pad_ms`).
3. **Подсказка модели** передаётся как `initial_prompt`; к ней добавляются слова пользователя из переменной `RASSHIFROVKA_EXTRA_PROMPT` (окно берёт их из `словарь.txt`).
4. **Говорящие по словам.** Фраза Whisper делится на том слове, где сменился голос; отрезки короче двух слов и 0,6 с остаются с соседом. В быстром диалоге реплики больше не слипаются в один абзац.
5. **Текст важнее говорящих.** Если разделение по голосам не удалось, расшифровка продолжается без него, а не обрывается с ошибкой.
6. **Тип вычислений на модель** — файл `compute_type.txt` в папке модели: "Быстрая" — та же large-v3-turbo в int8.
7. `cpufeature` необязателен — для Python 3.12 у него нет готовой сборки.
8. Сборка Windows: torchvision необязателен, добавлены модули scipy, без которых в собранном exe падало разделение голосов.
