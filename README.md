# Расшифровка

Программа для Windows, которая превращает записи разговоров в текст —
**без интернета**. Голосовые из WhatsApp, записи встреч и созвонов
расшифровываются на вашем компьютере; звук и текст никуда не отправляются.

- **История** — все расшифровки в одном месте: дата, время, название, поиск.
- **Кто говорит** — по желанию: тумблер "Разделять говорящих" в окне, которое открывается после выбора записи. Реплики разделены по голосам: "Говорящий 1", "Говорящий 2"; имя можно вписать. По умолчанию выключено: без разделения расшифровка примерно вдвое быстрее.
- **Слушать и читать вместе** — нажатие на абзац включает запись с этого места, текущий абзац подсвечен.
- **Запись разговора** — встреча (микрофон) или созвон (микрофон и звук компьютера: собеседник в WhatsApp, Zoom, Teams). После "Стоп" запись сразу уходит в расшифровку. Во время записи виден черновик текста.
- **Запись не теряется** — звук сохраняется на диск каждые 30 секунд. Если окно закрылось или компьютер выключился, при следующем запуске записанное появится в истории как "Восстановленная запись".
- **Расшифровка не прерывается** — она идёт отдельно от окна: окно можно закрыть, расшифровка продолжится. Пока она идёт, компьютер не засыпает. Если расшифровку всё же оборвал сбой, она сама начнётся заново. Видно этап, сколько осталось и уже готовый текст.
- **Голосовые из Загрузок** — новые записи из папки "Загрузки" видны одним списком, расшифровка — одной кнопкой.
- **Русский и казахский**, в том числе вперемешку; другие языки Whisper тоже работают.

Расшифровки лежат в `Документы\Расшифровки`: на каждую запись — папка с копией
звука, текстом (`transcript.md`) и описанием.

## Установка

Нужен Windows 10 или 11 и около 5 ГБ места. Видеокарта не нужна, но если
есть NVIDIA — установка найдёт её сама, и расшифровка пойдёт в разы быстрее
(ещё около 3 ГБ места).

1. Установите [Python 3.12](https://www.python.org/downloads/release/python-31210/) — при установке отметьте "Add python.exe to PATH".
2. Скачайте программу: зелёная кнопка **Code → Download ZIP** на этой странице, распакуйте в удобную папку (например, `Документы\Расшифровка`).
3. Нажмите правой кнопкой по `install.ps1` → **Выполнить с помощью PowerShell**. Установка скачает библиотеки и модель распознавания (~1,6 ГБ) — 10–30 минут в зависимости от интернета.
4. Откройте ярлык **"Расшифровка"** на рабочем столе.

Если PowerShell не даёт запустить файл, откройте PowerShell в папке программы и выполните:

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
```

## Скорость

На ноутбуке без видеокарты (Intel i3, 8 ГБ памяти) минута записи
расшифровывается примерно за 1,6 минуты в режиме "Быстрая" и за 3 минуты
в режиме "Точная" — это с разделением по голосам. Без него — примерно
вдвое быстрее. Пока идёт расшифровка, запись уже можно слушать.

С видеокартой NVIDIA распознавание и разделение голосов идут на ней:
на ноутбуке с RTX 3050 запись 16:51 с разделением по голосам — 2 минуты
вместо 22,5 минуты на процессоре Ryzen 5 5600H, без разделения — меньше минуты.
В окне "Как расшифровать" появляется выбор "Чем считать": "Видеокарта и
процессор" (по умолчанию) или "Только процессор" — если карта занята,
например игрой. Если видеокарта даст сбой, расшифровка сама продолжится
на процессоре.

Если видеокарта появилась после установки или программа ставилась раньше
этой версии — запустите `install.ps1` ещё раз: он поставит библиотеки для
видеокарты и ничего не сломает.

## Свои слова

Имена коллег, названия компаний и продуктов модель пишет точнее, если их
подсказать. Создайте файл `Документы\Расшифровки\словарь.txt` и перечислите
слова через запятую в одну строку. Файл остаётся у вас и в программу не попадает.

## Без интернета — как это устроено

- Программа и модели работают только с диска. Проверка обновлений и отправка статистики, которые были в исходном noScribe, удалены из кода.
- Окно — встроенный браузерный движок Chromium; страница загружается только из папки программы, сетевые службы движка выключены.
- Интернет нужен один раз — при установке, чтобы скачать библиотеки и модель.

Для полной гарантии можно запретить программе выход в сеть в брандмауэре
Windows. Правило ставится на файл программы, поэтому для него нужна сборка
в `.exe`:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Сборка запускается после `install.ps1`, идёт несколько минут и занимает около
3,5 ГБ: окно — `dist\Rasshifrovka\Rasshifrovka.exe`, движок —
`dist\noScribe\noScribe.exe`. В конце `build.ps1` печатает готовые
команды запрета сети для четырёх файлов: их выполняют один раз в PowerShell
от имени администратора. Пересобирайте на то же место — правила продолжат
действовать.
